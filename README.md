## Проекты

### Сайты и лендинги
Верстаю полноценные многостраничные сайты — с адаптивной вёрсткой, SEO-структурой и формами сбора заявок. Подключаю аналитику, оптимизирую скорость загрузки, настраиваю домены и хостинг.

**Стек:** HTML · CSS · JavaScript · Vercel / Netlify

---

### CRM-системы и базы данных
Строю внутренние CRM под конкретные бизнес-процессы — воронки сделок, карточки клиентов, история взаимодействий, статусы и напоминания. Не «коробочные» решения, а точно под нужную логику работы.

**Стек:** Supabase · PostgreSQL · Airtable · Notion API

---

### Телеграм-боты
Автоматизирую общение с клиентами и внутренние процессы через ботов: запись на занятия, рассылки, сбор обратной связи, напоминания.

**Стек:** Python · Aiogram · Telegram Bot API · Railway

---

### AI-агенты и автоматизации
Собираю агентов под задачи: анализ данных, генерация контента, обработка входящих заявок, follow-up-цепочки.

**Стек:** Claude API · n8n · Make · Zapier

---

### Аналитика и отчёты
Обрабатываю таблицы с данными о продажах: чищу, группирую, нахожу паттерны, возвращаю выводы в удобном формате. Строю дашборды и автоматические отчёты.

**Стек:** Python · Pandas · Google Sheets · Markdown

## Подход к работе

- **Вайбкодинг** — не хаос, а методология. Чёткое ТЗ + правильный промт + итерации = рабочий продукт.
- Делаю под задачу, не ради технологии. Если проблему решает таблица — беру таблицу. Нужна CRM — строю CRM.
- Каждый проект — это сначала понимание бизнес-логики, потом код.
